## 题目描述

本题所有图片均来源于谷歌街景，请自行准备相关工具。
OSINT系列通用靶机地址（请勿攻击平台）：https://osint.aristore.eu.org/
flag的格式是flag{纬度,经度}（注意中间的逗号为英文逗号，且没有空格，纬度和经度均精确到小数点后7位，假如你找到的经纬度不足7位请在其后用0填充）

## 提示

例子：假设你找到的是https://www.google.com/maps/place/.../@12.3456789,-98.7654321,3a,47.1y,48.97h,91.05t/data=...，那么flag就是flag{12.3456789,-98.7654321}
补全的例子：假设你找到的是https://www.google.com/maps/place/.../@12.345678,-87.654321,3a,47.1y,48.97h,91.05t/data=...，那么补全后得到flag为flag{12.3456780,-87.6543210}
